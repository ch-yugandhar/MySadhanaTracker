# Sadhana Tracker (installable phone app, no account, no backend)

Everything is stored on your phone. Works offline once installed.

## Install (about 3 minutes, one time)
1. On github.com create a new public repo (e.g. `sadhana`).
2. Upload every file from this folder to the repo root (Add file -> Upload files).
3. Repo Settings -> Pages -> Source: "Deploy from a branch" -> main / root -> Save.
4. After a minute your app is at https://<your-username>.github.io/sadhana/
5. Open that link on your phone:
   - Android (Chrome): menu -> Install app
   - iPhone (Safari): Share -> Add to Home Screen

Use "Export backup" now and then to keep a copy of your log.
